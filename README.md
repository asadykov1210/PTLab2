# PTLab2 — Магазин товаров для быта (Django)

Учебный проект по дисциплине «Программные технологии», выполненный в рамках индивидуального задания (Вариант 4).  
Приложение реализовано на фреймворке Django и представляет собой интернет-магазин с системой регистрации пользователей, корзиной и честной накопительной системой скидок.

---

## 🚀 Функциональность проекта

- **Регистрация и авторизация:** доступ к каталогу и корзине имеют только авторизованные пользователи. Для каждого покупателя ведется персональный учет.
- **Каталог товаров:** просмотр доступных товаров с ценами.
- **Корзина:** добавление товаров, изменение количества, удаление позиций. В корзине отображается стоимость *без учета скидки*.
- **Оформление заказа (Checkout):** перенос товаров из корзины в историю покупок.
- **Накопительная скидка:** скидка рассчитывается по количеству *фактически купленных* товаров (после оформления заказа) и применяется к следующим покупкам. Пороги скидок:
  - от 5 товаров — 5%
  - от 10 товаров — 10%
  - от 20 товаров — 15%
- **История покупок:** просмотр всех совершенных заказов с учетом примененных скидок.
- **Админ-панель:** управление товарами, пользователями и заказами через стандартный интерфейс Django.
