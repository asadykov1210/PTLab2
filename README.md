# PTLab2 — Магазин товаров для быта (Django)

Учебный проект по дисциплине «Программные технологии», выполненный в рамках индивидуального задания.  
Приложение реализовано на Django и включает модели товаров, покупателей, корзины, а также базовую логику скидок и покупок.

---

## 🚀 Функциональность проекта

- Просмотр списка товаров
- Расчёт скидки покупателя в зависимости от количества покупок
- Добавление товара в корзину
- Подтверждение покупки
- Просмотр корзины с итоговой суммой
- Удаление товара из корзины с обновлением количества покупок

---

## 🧪 Тестирование

Проект полностью покрыт тестами:

- **Модели:** Product, Customer, CartItem  
- **Представления (views):** index, add_to_cart, confirm_add, cart, remove_from_cart  
- **Количество тестов:** 17  
- **Результат:** все тесты проходят успешно

Запуск тестов:

python manage.py test shop.tests

Покрытие тестами (Coverage)

Команды:

coverage run --source=shop manage.py test shop.tests

coverage report -m
